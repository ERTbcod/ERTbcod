## 🎓 Formação Acadêmica

### ⚙️ Engenharia de Controle e Automação — IFSP Hortolândia
*Cursando o 4º Semestre*

#### 📌 Evolução por Semestre:

* **1º Semestre**
  * **Desenho Técnico:** Modelagem 3D e CAD no OnShape.

* **2º Semestre**
  * **Programação 1:** Linguagem C (Algoritmos, estruturas condicionais, repetição, `structs` e ponteiros).
  * **Sistemas Computacionais 1:** Arquiteturas hipotéticas (*Ahmes, Ramses, Cesar*) utilizando o montador **Daedalus**.
  * **Eletrônica Digital:** Portas lógicas, simplificação de circuitos e sistemas digitais.
  * **Circuitos Elétricos:** Análise de circuitos, capacitores e indutores.
  * 🧪 **Projeto Prático (Química 2):** Simulador Web de Controle de Reação — [Acessar Projeto](https://projeto-quimica2-controle-reacao.netlify.app/)

* **3º Semestre**
  * **Programação 2:** Aprofundamento em Linguagem C (estruturas de dados avançadas e ponteiros).
  * **Microcontroladores:** Programação em C para arquitetura AVR (**Família ATmega**).
  * **Eletrônica Analógica:** Filtros, amplificadores operacionais e tratamento de sinais.
  * **Sistemas Computacionais 2:** Fundamentos de redes e formação em *Introdução à Cibersegurança* pela **Cisco**.

* **4º Semestre**
  * **Programação 3:** Programação Orientada a Objetos em **C++** (Classes, Herança, Polimorfismo e Templates).
  * **Cálculo Numérico:** Métodos analíticos e numéricos aplicados no **MATLAB**.
